# BrainHero Website

Official landing page for **BrainHero: Brain Training**, an iPhone app featuring quick daily games for memory, logic, math, focus, and reaction.

The website is built with static HTML, CSS, and JavaScript. It includes a responsive landing page, App Store download call-to-action, custom BrainHero artwork, and SEO/AEO metadata.

## Local preview

```bash
python3 -m http.server 8000
```

Open `http://localhost:8000` in a browser.
